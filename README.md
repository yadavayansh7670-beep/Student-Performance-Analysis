
# Student Performance Analysis System

A Python and NumPy based project that analyzes student academic performance using numerical computing and array operations.

## Project Overview

This project analyzes marks of 10 students across 5 subjects and generates useful academic performance insights.

## Features

- Student dataset creation using NumPy
- Total and average marks calculation
- Highest and lowest marks identification
- Overall topper identification
- Top 3 student ranking
- Subject-wise topper analysis
- Pass and Fail classification
- Student performance report
- Overall statistical analysis

## Technologies Used

- Python
- NumPy
- Google Colab

## NumPy Concepts Used

- NumPy Arrays
- Array Indexing and Slicing
- Array Aggregation
- Axis Operations
- Boolean Indexing
- np.sum()
- np.mean()
- np.max()
- np.min()
- np.argmax()
- np.argsort()
- np.where()
- np.all()

## Dataset Information

- Total Students: 10
- Total Subjects: 5
- Total Records: 10
- Maximum Marks: 500 per student

- Maths
